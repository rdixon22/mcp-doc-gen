    list_thoughts

    Browse recently captured thoughts in newest-first order. Unlike semantic search tools, list_thoughts issues a direct database query — no embedding is generated — making it the fastest way to retrieve recent entries or enumerate thoughts matching a known attribute.

    Use this tool when you want to browse rather than search: recent captures, all tasks, everything tagged with a topic, or everything mentioning a specific person.

    Parameters

    All parameters are optional. Omitting all of them returns the 10 most recently captured thoughts.

    Parameter Type Required Default Description
    limit number No 10 Maximum number of results to return.
    type string No — Filter by thought type. Must be one of: observation, task, idea, reference, person_note.
    topic string No — Filter by topic tag (matched against the topics array in the entry's JSONB metadata).
    person string No — Filter by a person mentioned (matched against the people array in the entry's JSONB metadata).
    days number No — Restrict results to thoughts captured in the last N days.

    Filter behaviour

    All supplied filters are ANDed together. A thought must satisfy every specified filter to appear in results. For example, type=task + person=Alice + days=7 returns only tasks mentioning Alice from the past week.

    Returns

    A formatted text list of matching thoughts, newest first. Each entry includes:

    • Capture date and time
    • Thought type (e.g. task, idea)
    • Topic tags
    • People mentioned
    • Action items (if any)
    • Full thought content

    If no thoughts match the filters, the tool returns an empty result with a count of zero.

    When to use list_thoughts vs. other tools

    Situation Recommended tool
    You know the attribute (type, topic, person) list_thoughts
    You want recent captures without a specific query list_thoughts
    You have a concept or question to search by meaning search_thoughts
    You need to search both thoughts and wiki pages search_all
    You want a count and breakdown of all entries thought_stats

    Usage examples

    Get the 10 most recent thoughts (no filters)

    {
  "name": "list_thoughts",
  "arguments": {}
}

    Show recent tasks from the last 7 days

    {
  "name": "list_thoughts",
  "arguments": {
    "type": "task",
    "days": 7
  }
}

    Show all thoughts mentioning a specific person

    {
  "name": "list_thoughts",
  "arguments": {
    "person": "Alice Smith",
    "limit": 25
  }
}

    Narrow to tasks about a topic from the past month

    {
  "name": "list_thoughts",
  "arguments": {
    "type": "task",
    "topic": "machine-learning",
    "days": 30,
    "limit": 20
  }
}

    Browse all ideas, no time limit

    {
  "name": "list_thoughts",
  "arguments": {
    "type": "idea",
    "limit": 50
  }
}

    Implementation notes

    list_thoughts queries the entries table in Supabase directly, filtering on source != 'wiki' to exclude WikiVault pages. Type, topic, and person filters use PostgreSQL's JSONB .contains() operator against the metadata column (which is populated at capture time by the LLM metadata-extraction step). The days filter translates to a created_at >= now() - interval 'N days' clause. Results are ordered by created_at descending.

    Because no Ollama embedding call is made, this tool completes faster than search_thoughts or search_all and does not require the Ollama service to be running.
