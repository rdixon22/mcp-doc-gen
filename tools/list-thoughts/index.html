    list_thoughts

    Browse recently captured thoughts with optional filters. Use this tool when you want a list of thoughts rather than a semantic search — for example, to audit recent captures, review open tasks, or see what was noted about a specific person or topic.

    All parameters are optional. Omit all of them to retrieve the most recently captured thoughts up to the default limit.

    Parameters

    Parameter Type Required Default Description
    limit number No 10 Maximum number of results to return.
    type string No — Filter by thought type. Accepted values: observation, task, idea, reference, person_note.
    topic string No — Filter by topic tag.
    person string No — Filter by person mentioned.
    days number No — Restrict results to thoughts captured within the last N days.

    Returns

    An ordered list of thought entries matching the supplied filters. Each entry includes the thought's content, metadata, and timestamp. No filters applied returns up to limit thoughts.

    Usage examples

    Browse recent thoughts (no filters)

    {
  "tool": "list_thoughts",
  "params": {}
}

    Returns up to 10 recently captured thoughts.

    List all captured tasks

    {
  "tool": "list_thoughts",
  "params": {
    "type": "task"
  }
}

    Tasks mentioning Alice Smith from the last 7 days

    {
  "tool": "list_thoughts",
  "params": {
    "type": "task",
    "person": "Alice Smith",
    "days": 7
  }
}

    Returns task-type thoughts that mention Alice Smith and were captured within the last 7 days.

    Ideas tagged with a specific topic, larger result set

    {
  "tool": "list_thoughts",
  "params": {
    "type": "idea",
    "topic": "product-strategy",
    "limit": 25
  }
}

    Recent observations (last 3 days)

    {
  "tool": "list_thoughts",
  "params": {
    "type": "observation",
    "days": 3
  }
}

    When to use list_thoughts vs. other tools

    Goal Recommended tool
    Browse or audit recent captures by recency list_thoughts
    Find thoughts by meaning or topic without knowing exact tags search_thoughts
    Search across both thoughts and wiki pages search_all
    Get aggregate counts and breakdowns thought_stats

    Notes

    • All parameters are optional and combinable — supply any combination of type, topic, person, and days to narrow results.
    • When no filters are provided, results are limited to limit entries (default 10).
    • Use search_thoughts if you want to find thoughts by semantic similarity rather than by explicit metadata filters.
