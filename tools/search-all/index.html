    search_all

    Performs a unified semantic search across all Cortex stores at once: captured thoughts (from web, Discord, and MCP capture) and WikiVault pages. Results are returned as a single merged, ranked list with each item tagged [thought] or [wiki] by its source.

    Use search_all when you need the broadest possible context or are unsure which store contains the relevant information. When you know the information lives in a specific store, prefer the targeted tool (search_thoughts or search_wiki) for more focused results.

    Parameters

    Parameter Type Required Default Description
    query string Yes — The search query — phrase or natural language description of what to find
    limit number No 15 Maximum number of results to return across all stores combined
    threshold number No 0.45 Minimum similarity score (0–1); lower than single-store search defaults to surface cross-store results

    Notes on threshold

    The default of 0.45 is intentionally lower than single-store search tools. This ensures relevant results are not dropped when retrieving across multiple stores with different content densities. Raise the threshold (e.g. 0.6–0.7) to return only high-confidence matches; lower it toward 0.3 to cast the widest net.

    Returns

    A merged list of results ranked by semantic similarity score. Each result includes:

    • Source tag — [thought] for captured thoughts, [wiki] for WikiVault pages
    • Content or title — the text snippet or page title matched
    • Similarity score — a value between 0 and 1 indicating relevance to the query

    Note: The exact field names in the returned objects are illustrative. Treat the source tag, content, and score as the canonical information each result carries.

    Usage examples

    Broad context search — unknown store

    {
  "name": "search_all",
  "arguments": {
    "query": "decisions about the auth service"
  }
}

    Returns up to 15 results mixing [thought] entries (e.g. a captured observation about switching to JWT) and [wiki] pages (e.g. a project page for the auth service), ranked by similarity.

    High-confidence search with tighter threshold

    {
  "name": "search_all",
  "arguments": {
    "query": "onboarding checklist for new engineers",
    "limit": 5,
    "threshold": 0.65
  }
}

    Returns at most 5 results, all with similarity ≥ 0.65 — useful when you want only the most directly relevant matches.

    Finding everything about a person

    {
  "name": "search_all",
  "arguments": {
    "query": "Alice Smith",
    "limit": 20,
    "threshold": 0.4
  }
}

    Surfaces both [wiki] pages (e.g. a person page for Alice Smith) and [thought] entries (e.g. notes captured after meetings with her) in a single ranked list.

    Choosing between search tools

    Situation Recommended tool
    Don't know which store has the information search_all
    Need the broadest context on a topic search_all
    Know the information is a captured thought search_thoughts
    Know the information is in a wiki page search_wiki
    Know the exact wiki page title read_wiki_page
    Want recent thoughts without a query list_thoughts
    Want to browse wiki pages by type list_wiki_pages

    Related tools

    • search_thoughts — semantic search scoped to captured thoughts only
    • search_wiki — semantic search scoped to WikiVault pages only
    • list_thoughts — chronological browse of captured thoughts with filters
    • list_wiki_pages — browse wiki pages by type or tag
    • read_wiki_page — retrieve a single wiki page by title or path
