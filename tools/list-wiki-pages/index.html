    list_wiki_pages

    Browse WikiVault pages with optional filters. Returns title, type, tags, and file path for each matching page — no page bodies. Operates via filesystem scan, so it works without a Supabase/DB connection.

    Use this tool for enumeration tasks — listing all pages of a given type, finding all pages with a specific tag, or auditing coverage. For meaning-based discovery (e.g. "pages about machine learning"), use search_wiki instead.

    Parameters

    Parameter Type Required Default Description
    type string (enum) No — Filter results to one page type. See valid values below.
    tag string No — Filter by a single tag.
    limit number No 50 Maximum number of results to return.

    Valid type values

    Value Description
    wiki_person Person profile pages
    wiki_project Project pages
    wiki_concept Concept or idea pages
    wiki_area Area-of-responsibility pages
    wiki_topic Topic overview pages
    raw_article Imported article content
    raw_book Imported book notes
    raw_daily Daily note entries
    raw_attachment Attachment files

    All parameters are optional. Calling list_wiki_pages with no arguments returns up to 50 pages across all types.

    Returns

    A list of matching pages. Each result includes:

    • title — the human-readable page title
    • type — the page type (one of the enum values above)
    • tags — array of tags associated with the page
    • file path — the relative path to the page file in WikiVault

    No page bodies are returned. To read a page's full content, pass its title or file path to read_wiki_page.

    Usage Examples

    List all person pages

    {
  "type": "wiki_person"
}

    List all pages tagged "engineering"

    {
  "tag": "engineering"
}

    List person pages tagged "engineering"

    {
  "type": "wiki_person",
  "tag": "engineering"
}

    Returns all wiki_person pages that carry the engineering tag — useful for auditing which engineers have wiki entries.

    List all pages, increased limit

    {
  "limit": 100
}

    List raw articles, capped at 20

    {
  "type": "raw_article",
  "limit": 20
}

    When to Use This Tool

    Goal Tool
    List all pages of a given type list_wiki_pages with type
    Find pages with a specific tag list_wiki_pages with tag
    Find pages by meaning or topic search_wiki
    Read a specific page's content read_wiki_page
    Search thoughts and wiki together search_all

    Notes

    • Results are limited to metadata only. The tool does not return page bodies, so follow up with read_wiki_page for full content.
    • type and tag filters are independent and can be combined. When both are provided, results must satisfy both conditions.
    • Because this tool scans the filesystem rather than querying the database, it reflects the current state of files on disk and does not require Supabase to be available.
