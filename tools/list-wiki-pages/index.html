    list_wiki_pages

    Browse WikiVault pages with optional filters. Returns title, type, tags, and file path — no body content. Operates entirely from a filesystem scan, so it works even when Supabase is unavailable.

    Use list_wiki_pages when you need to enumerate pages ("show me all people", "list every stub") rather than rank by relevance. For relevance-ranked discovery use search_wiki; for full body content use read_wiki_page.

    Parameters

    Parameter Type Required Default Description
    type string No — Restrict results to one page type (see allowed values below)
    tag string No — Filter by a single tag (lowercase-kebab)
    limit number No 50 Maximum number of results to return

    type allowed values

    Value Description
    wiki_person People profiles
    wiki_project Project pages
    wiki_concept Concept definitions
    wiki_area Areas of responsibility or interest
    wiki_topic Topic overviews
    raw_article Imported articles
    raw_book Imported book notes
    raw_daily Daily notes
    raw_attachment Attachment files

    Returns

    A list of page summaries, sorted by title. Each entry includes:

    • title — human-readable page title from frontmatter
    • type — the page type (one of the values above)
    • tags — array of lowercase-kebab topic tags
    • file_path — relative path within the WikiVault directory (e.g. wiki/people/Alice-Smith.md)

    Bodies are not returned. Call read_wiki_page with the file_path to retrieve full content.

    The following special files are automatically excluded from all results: SCHEMA.md, index.md, log.md.

    Behavior notes

    • No database required. The tool walks the WikiVault directory directly; Supabase does not need to be reachable.
    • Tag filtering matches against the tags array in each page's YAML frontmatter. Pass the tag exactly as it appears in frontmatter (lowercase-kebab format, e.g. machine-learning).
    • Filters combine. Specifying both type and tag returns pages matching both conditions.
    • Limit applies after filtering. Results are capped at limit after type and tag filters are applied.

    Usage examples

    List all people

    {
  "name": "list_wiki_pages",
  "arguments": {
    "type": "wiki_person"
  }
}

    List all stub pages

    {
  "name": "list_wiki_pages",
  "arguments": {
    "tag": "stub"
  }
}

    List project pages tagged with a specific topic

    {
  "name": "list_wiki_pages",
  "arguments": {
    "type": "wiki_project",
    "tag": "machine-learning",
    "limit": 20
  }
}

    List all pages (no filters, increased limit)

    {
  "name": "list_wiki_pages",
  "arguments": {
    "limit": 200
  }
}

    Choosing between list and search

    Goal Tool
    Enumerate all pages of a type list_wiki_pages
    Find pages by meaning / topic search_wiki
    Read a specific page's content read_wiki_page
    Search thoughts and wiki together search_all

    Related tools

    • search_wiki — semantic search over wiki pages (requires database)
    • read_wiki_page — read full body and frontmatter of a single page
    • write_wiki_page — create or update a wiki page
    • append_wiki_log — add an audit entry after wiki changes
