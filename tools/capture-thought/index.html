    capture_thought

    Save a new note or thought to Cortex. Automatically embeds and extracts metadata (topics, type, people, action items). Use when the user wants to save an insight, decision, observation, or task.

    Parameters

    Parameter Type Required Default Description
    content string Yes — The thought to capture — a clear, self-contained statement

    content guidance

    Write content as a complete, standalone statement that will make sense when read back later without surrounding context. Include relevant names, project references, and decisions inline. A vague fragment like "discussed auth" is less useful than "Decided to migrate the auth service to OAuth 2.0 by end of Q3 — owner: Alice Smith".

    Returns

    The tool returns a confirmation that the thought was saved, along with the extracted metadata Cortex derived automatically — which may include the inferred thought type, topics, people mentioned, and any action items detected in the content. The exact shape of the returned object is determined by the server at runtime.

    When to use

    • The user explicitly asks to save, capture, note, or remember something.
    • An important insight, decision, or task surfaces during a conversation that should be persisted beyond the current session.
    • You want to create a record that can later be retrieved via search_thoughts, list_thoughts, or thought_stats.

    Usage examples

    Capture a decision

    {
  "content": "Decided to migrate the auth service to OAuth 2.0 by end of Q3 — owner: Alice Smith"
}

    Cortex will automatically extract topics (e.g. auth, oauth), identify Alice Smith as a person mentioned, and classify the thought type based on the content.

    Capture an observation

    {
  "content": "The onboarding funnel drop-off rate spiked 12% after the v2.4 release — likely caused by the new email verification step"
}

    Capture a task

    {
  "content": "Follow up with the infrastructure team about the load balancer timeout settings before the next deploy"
}

    Notes

    • Pass the full context in content — Cortex uses the text itself to generate the embedding and infer metadata, so richer input produces more useful extraction and retrieval.
    • There is no separate type or topic parameter on this tool; all classification is derived automatically from the content string.
    • After capturing, use search_thoughts to verify the thought is retrievable by meaning, or list_thoughts to browse recent entries chronologically.
