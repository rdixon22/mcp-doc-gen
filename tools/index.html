    Tools Index

    Thought Capture & Browsing

    Tool Description
    capture_thought Save a new note with automatic metadata extraction (topics, type, people, action items)
    list_thoughts Browse recently captured thoughts with optional filters for type, topic, person, and recency
    thought_stats Get summary counts and breakdowns: total thoughts, type distribution, top topics and people

    Semantic Search

    Tool Description
    search_thoughts Semantic search over captured thoughts only
    search_messages Semantic search over past AI chat conversation messages
    search_wiki Semantic search over WikiVault pages, with optional type filter
    search_all Unified semantic search across all stores (thoughts + wiki pages); results tagged by source

    Wiki Authoring

    Tool Description
    write_wiki_page Create or overwrite a WikiVault page; auto-builds frontmatter and indexes content
    read_wiki_page Read full body and frontmatter of a WikiVault page by title or file path
    list_wiki_pages Browse wiki pages by type or tag via filesystem scan; returns titles, types, tags, paths — no bodies
    append_wiki_log Write a one-line audit log entry to log.md after any write action

    Vault Migration

    Tool Description
    migrate_vault_file One-time import of a MainVault file into WikiVault raw/; normalizes frontmatter, strips Dataview blocks, embeds, and indexes

    Choosing the Right Search Tool

    Goal Use
    Search captured notes and thoughts only search_thoughts
    Search past AI chat conversations search_messages
    Search wiki pages only (people, projects, concepts, etc.) search_wiki
    Broadest search / unknown which store holds the information search_all

    search_all has a lower default threshold (0.45 vs 0.5) and returns results tagged [thought] or [wiki] so you can distinguish sources.

    Choosing the Right Write Tool

    Goal Use
    Save an atomic note, insight, decision, or task capture_thought
    Create or update a structured wiki page (person, project, concept, area, topic) read_wiki_page → write_wiki_page
    Import a legacy file from MainVault into WikiVault raw/ migrate_vault_file

    Read-Before-Write Protocol

    Never call write_wiki_page on a page that may already exist without first reading it. Follow these steps:

    1. Call read_wiki_page with the target page title or relative file path.
    2. Inspect the returned body and frontmatter for existing content, tags, sources, and status.
    3. Merge or update content as needed — preserving information you are not explicitly replacing.
    4. Call write_wiki_page with the full revised body (including all retained content).
    5. Call append_wiki_log with the file path and a one-line summary of what was changed.

    Skipping step 1 risks silently clobbering existing knowledge. write_wiki_page performs a full overwrite — there is no partial-update operation.
