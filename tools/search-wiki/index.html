    search_wiki

    Search WikiVault pages by semantic similarity. Results are ranked by relevance score. Use this tool when you don't know the exact page title and need to discover wiki entries by meaning rather than name. To enumerate all pages of a given type, use list_wiki_pages instead.

    Parameters

    Parameter Type Required Default Description
    query string Yes — What to search for. Interpreted semantically — phrase it as a concept, topic, or question.
    limit number No 10 Maximum number of results to return.
    threshold number No 0.5 Minimum similarity score (0–1). Results below this score are excluded. Lower values return more (looser) matches; higher values return only close matches.
    type string No — Restrict results to one page type. Must be one of the enum values below. Omit to search all wiki types.

    type enum values

    Value Description
    wiki_person People pages
    wiki_project Project pages
    wiki_concept Concept / idea pages
    wiki_area Area-of-life pages
    wiki_topic Topic / subject pages
    raw_article Imported articles
    raw_book Imported books
    raw_daily Daily notes
    raw_attachment Attachments

    Returns

    A ranked list of matching WikiVault pages. Each result includes:

    • title — human-readable page title
    • type — page type (one of the enum values above)
    • tags — array of topic tags
    • file_path — relative path to the file in WikiVault
    • score — similarity score (0–1), higher is more relevant

    Results are ordered by descending similarity score.

    Usage examples

    Basic search across all wiki types

    {
  "name": "search_wiki",
  "arguments": {
    "query": "transformer architecture"
  }
}

    Narrow to concept pages with a tighter threshold

    {
  "name": "search_wiki",
  "arguments": {
    "query": "transformer architecture",
    "type": "wiki_concept",
    "limit": 5,
    "threshold": 0.65
  }
}

    Returns up to 5 concept pages semantically related to transformer architecture, excluding any results with similarity below 0.65.

    Find people related to a domain

    {
  "name": "search_wiki",
  "arguments": {
    "query": "machine learning researchers",
    "type": "wiki_person",
    "limit": 10
  }
}

    Broad search with relaxed threshold

    {
  "name": "search_wiki",
  "arguments": {
    "query": "product launch strategy",
    "threshold": 0.35,
    "limit": 20
  }
}

    Useful when relevant pages may use different terminology than your query.

    Choosing between search tools

    Goal Tool
    Search wiki pages by meaning search_wiki
    Search captured thoughts by meaning search_thoughts
    Search wiki + thoughts together search_all
    Browse all pages of a given type list_wiki_pages
    Read a page you already know the title of read_wiki_page

    Notes

    • search_wiki searches WikiVault pages only — it does not surface captured thoughts or chat messages. Use search_all for combined results.
    • Adjusting threshold down (e.g. 0.3) is useful when queries use different vocabulary than the stored pages. Adjusting it up (e.g. 0.7) filters to only high-confidence matches.
    • If you know the exact page title, call read_wiki_page directly rather than searching.
    • Before calling write_wiki_page, run search_wiki to check whether a relevant page already exists — then use read_wiki_page to load its current content before overwriting.
