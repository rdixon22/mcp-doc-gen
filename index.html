    Cortex — Overview

    Cortex (v2.0.0) is a personal knowledge management MCP server that lets you capture, search, and synthesise information across two distinct stores. It runs over stdio transport, uses Supabase for vector embeddings, and exposes its full surface through MCP tools.

    Two Stores, One Knowledge Base

    Thoughts Store

    Thoughts are atomic, source-agnostic entries. When you capture a thought, Cortex automatically embeds it and extracts structured metadata — topics, type classification, people mentioned, and action items. Thoughts can originate from any source: direct MCP capture, web ingestion, or Discord. They are designed to be ephemeral working memory: low friction to create, fast to search by meaning, and filterable by type, topic, person, or recency.

    Thought types: observation, task, idea, reference, person_note

    WikiVault Store

    WikiVault pages are durable, structured markdown files with auto-generated frontmatter. They are LLM-maintained — intended to be created and updated by an AI agent synthesising information from Thoughts and raw sources. Pages live in typed subfolders and are indexed in Supabase alongside their embeddings.

    Wiki types (curated knowledge):

    Type Purpose
    wiki_person Profile pages for people
    wiki_project Project summaries and status
    wiki_concept Concept definitions and explanations
    wiki_area Broad life/work area overviews
    wiki_topic Topic-level knowledge aggregations

    Raw types (imported source material):

    Type Purpose
    raw_article Articles imported from MainVault or web
    raw_book Book notes and highlights
    raw_daily Daily notes
    raw_attachment Supporting files and attachments

    Functional Areas

    1. Thought Capture & Browsing

    Save atomic notes with capture_thought. Metadata extraction is automatic — you supply only the content. Browse what you've captured chronologically with list_thoughts, or get an aggregate summary via thought_stats.

    2. Semantic Search

    Find content by meaning, not just keywords. Cortex provides scoped and combined search:

    • search_thoughts — thoughts only
    • search_wiki — WikiVault pages only, with optional type filter
    • search_messages — past AI chat conversation history
    • search_all — all stores simultaneously; results tagged [thought] or [wiki]

    All semantic search tools use configurable similarity thresholds and result limits.

    3. Wiki Authoring

    Create and maintain structured knowledge pages with a strict read-before-write protocol:

    1. read_wiki_page — always call this first if the page may exist
    2. write_wiki_page — create or overwrite with merged content
    3. append_wiki_log — record what was done in log.md

    list_wiki_pages lets you enumerate all pages of a given type without reading their bodies, using a filesystem scan that requires no database.

    4. Vault Migration

    migrate_vault_file imports individual files or batch-migrates from a legacy MainVault into WikiVault's raw/ subfolders. It adds standardised frontmatter, strips Dataview blocks, embeds the content, and indexes it in Supabase — without modifying the original source file.

    Typical Workflows

    Capture → Search → Synthesise

    1. capture_thought        — save an insight or observation
2. search_thoughts        — resurface relevant past thoughts by meaning
   OR search_all          — cast a wider net across thoughts + wiki
3. read_wiki_page         — check whether a synthesis page already exists
4. write_wiki_page        — create or update the wiki page with synthesised content
5. append_wiki_log        — record the action taken

    Import → Discover → Reference

    1. migrate_vault_file     — import a legacy article or book note into raw/
2. search_wiki            — find the imported page by meaning
3. write_wiki_page        — create a wiki page that lists it as a page_source
4. append_wiki_log        — record the new page and its sources

    Daily Review

    1. list_thoughts          — browse recent captures (filter by days=1 or days=7)
2. thought_stats          — see type and topic distribution across all captures
3. search_messages        — find relevant things discussed in past AI sessions
4. write_wiki_page        — update a person or project page with new information

    Architecture Notes

    • Transport: stdio — Cortex runs as a subprocess, communicating over standard input/output.
    • Vector store: Supabase stores embeddings for both Thoughts and WikiVault pages, enabling semantic similarity search across all content.
    • Auto-embedding: Both capture_thought and write_wiki_page automatically generate and store embeddings on write — no separate indexing step required.
    • Frontmatter management: write_wiki_page builds frontmatter automatically from structured parameters. Do not include frontmatter in the body parameter.
    • Read-before-write enforcement: write_wiki_page performs a full overwrite. Always call read_wiki_page first when a page might already contain content, merge your changes, then write the combined result.
    • Audit trail: append_wiki_log appends to a single log.md file in WikiVault. Call it after every write_wiki_page or significant decision to maintain a recoverable history of changes.
